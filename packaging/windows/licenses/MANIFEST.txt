# Third-party licenses shipped with the Windows package.
#
# Each line: <destination file name>|<source path relative to the repo root>|<kind>
#
#   copied    the file is copied into licenses/ in the package as-is
#   pkg       the license belongs to an MSYS2 package; source is resolved from
#             /clang64/share/licenses/<package>/LICENSE at build time
#   optional  shipped only when its source file exists (the DLSS bridge, built
#             separately); a missing source is reported, not fatal
#
# packaging/windows/check_licenses.sh verifies that every entry whose file can
# be located actually ends up in the package, and fails the build when a
# license the binary links is missing. Run it with no arguments to check the
# current working tree (use --stage DIR to check an assembled package).
#
# Keep in sync with the credits list in README.md.
